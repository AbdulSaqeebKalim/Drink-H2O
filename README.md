# 🌊 Drink H2O — Daily Hydration Tracker

**Drink H2O** is a lightweight, intuitive web application designed to help users track their daily water intake and achieve their hydration goals effortlessly. Built with clean web technologies and generated/assisted by **Google AI Studio**.

---
## 💧 Try it Live

- https://github.com/AbdulSaqeebKalim/Drink-H2O

## ✨ Features

- 💧 **Visual Water Tracking:** Easily log water consumption throughout the day.
- 🎯 **Daily Goal Monitoring:** Set target water intake and track real-time progress toward your goal.
- 📊 **Interactive UI:** Smooth, modern, and mobile-friendly interface designed for seamless logging.
- 💾 **Local Persistence:** Retains tracking state across page refreshes using browser storage.
- ⚡ **Lightweight & Fast:** Zero heavy framework dependencies, ensuring instantaneous load times.

---

## 🛠️ Built With

- **HTML5 & CSS3** — Responsive layout and custom styling.
- **JavaScript (ES6+)** — Core application logic and local storage integration.
- **Google AI Studio** — AI-assisted development and rapid prototyping.
